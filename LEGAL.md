# Legal and Project Identity

## Project Identity

**die Nische** is an independent web desktop project inspired by the KDE 3
desktop environment. It recreates aspects of historical KDE 3 visual design
and application interaction through a browser-based implementation.

## Independence and Non-Affiliation

die Nische is an independent and unofficial project. It is not affiliated
with, endorsed by, sponsored by, or otherwise associated with KDE e.V. or the
KDE Community.

KDE 3 is historical inspiration, a UI/UX reference, and a recreation target.
KDE 3 is not the parent brand of die Nische.

## Recreated Applications

Interfaces presented by die Nische that use historical names such as
Konqueror, Konsole, KWrite, KCalc, and KFind are browser-based or historical
interface recreations. They are not the original KDE applications. These names
are used descriptively to identify the historical applications or interfaces
being recreated; die Nische does not claim to have renamed or forked them, nor
does it imply binary or source compatibility with KDE.

In particular, the Konqueror interface is a browser-based recreation inspired
by the historical KDE Konqueror application. It is not the original KDE
Konqueror application.

## Virtual Filesystem and Simulated Environment

The filesystem presented by die Nische is a browser-based virtual/simulated
filesystem. Paths, files, directories, devices, and system locations shown
inside the desktop do not represent or provide access to the user's actual
operating-system filesystem unless a feature explicitly states otherwise.

The browser desktop, terminal, system information, virtual filesystem, and
simulated system paths are part of the die Nische browser environment. System
information pages do not represent the user's real operating-system state
unless an individual field explicitly says that it does.
